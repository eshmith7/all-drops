DEFINITION

Node

One step that does one job. It receives data, does something, passes data on. A workflow is nodes plus the connections between them.

DEFINITION

Trigger

The starting node. Every workflow needs exactly one. Here it's the Chat Trigger — it fires when a message arrives and one execution begins.

02

The ports underneath the agent.

An AI Agent node has the usual input on the left and output on the right — plus a row of ports underneath. The Chat Model port is required; Memory and Tool are not. Flip the switches and watch what the same agent can and can't do. Anything hanging off those bottom ports is a sub-node.

DEFINITION

Chat Model port

The agent's brain slot. Required. Leave it empty and the node errors the moment it runs. Here: OpenAI Chat Model, gpt-4o-mini.

DEFINITION

Sub-node

A node attached underneath another one, on a dotted downward connection. It never runs on its own — the parent node calls it.

DEFINITION
System prompt

      
The instruction you type into the agent node. Short and specific beats long and vague — every extra job dilutes the ones already there.

    
DEFINITION
Specialist agent

      
An agent with one job, its own chat model and its own tools. You upgrade it without touching anything else on the canvas.

  







  
04

  
An agent can be a tool.

  
Attach an agent to another agent's Tool port and the parent stops treating it as a chat partner — it calls it like a function. What decides whether it gets called at all is the tool description. Pick one and run "Analyze Infosys".

DEFINITION
Tool port

      
Takes zero or many sub-nodes. Anything on it is something the agent may choose to call — SerpAPI, a Code tool, or another agent.

    
DEFINITION
Tool description

      
Not documentation — routing logic. It is the only thing the orchestrator reads when deciding which tool to call. Vague description, wrong tool.

  







  
05

  
What actually moves down the wire.

  
Data travels as a list of items — each one a JSON object. A node runs once per item, and an expression is how the next node reaches into it. Click along the line and inspect what's really there.

DEFINITION
Item

      
One JSON object travelling between nodes. Data moves as a list of items, and a node runs once for each one it receives.

    
DEFINITION
Expression

      
Double curly braces that pull a field out of the incoming item — {{ $json.output }}. It's how nodes talk about each other's data.

The last mile: an analysis nobody reads.

  
The Code node turns the agent's plain text into styled HTML and returns it as items. Then Gmail has one setting that ruins everything — Message Type. Flip the three switches and watch the inbox.

DEFINITION
Code node

      
Runs your JavaScript inside the workflow. It must return items — return [{ json: { html } }] — or nothing reaches the next node.

    
DEFINITION
Message Type

      
A Gmail node setting: Text or HTML. Leave it on Text while sending HTML and your reader gets raw tags. The classic beginner bug.
