DEFINITION

RAG pipeline

Index → retrieve → rerank → generate, with evaluate wrapped around all of it. Indexing runs once per document change. Everything else runs on every question.

DEFINITION

Retrieval failure

The right passage existed and the retriever didn't hand it over. The model then answers fluently from whatever it was given — so the failure is invisible in the output.

02

Chunking decides what is answerable.

A chunk is the unit of what can be retrieved. Split this handbook page yourself and watch two facts that belong together get separated — or a chunk grow so broad it stops being about anything. Parent-document retrieval and structure-aware splitting are the ways out.

DEFINITION

Chunk

One retrievable piece of a document. If the answer is split across two chunks, no retriever can save you. A common baseline is 256–512 tokens with 10–20% overlap.

DEFINITION

Parent-document retrieval

Index the small chunk so matching stays precise, then return the larger parent section as context. You get sharp retrieval and whole tables. Standard upgrade.

03

Embeddings measure similarity, not truth.

Every chunk becomes an embedding — a point in space. Near means “worded alike”, which is not the same as “correct”. Click a chunk to see its nearest neighbours by cosine similarity, then move top-k and watch which ones make the cut.

Try it
DEFINITION

Embedding

Text turned into coordinates — typically 1024 to 1536 numbers. Similar meaning, nearby vectors. The map here is that space flattened to two dimensions so you can see it.

DEFINITION

Cosine similarity

How aligned two vectors are, 0 to 1. It scores wording, not accuracy — a paragraph about the wrong leave type scores high if it is written the same way.

04

Hybrid, then rerank.

“Casual leave” is an exact phrase the employee typed — exactly what BM25 is good at and dense retrieval smears over. Fuse the two lists, then let a reranker read each chunk against the question. Watch the correct chunk go 7 → 3 → 1.

Try it
DEFINITION

BM25 / hybrid search

Keyword scoring that rewards rare exact terms — IDs, acronyms, policy names. Run it alongside dense retrieval and fuse the two rankings. Hybrid is the default now, not an optimisation.

DEFINITION

Reranker

A cross-encoder reads the question and the chunk together, so it judges far better than a vector distance — and is far too slow to run over the whole corpus. That is why it goes second.

05

Lost in the middle.

Retrieval worked. The right chunk is in the prompt — fifth of nine. Models attend best to the start and the end of a long context and genuinely miss what sits between: lost in the middle, Liu et al., 2023. Reorder the context and watch what the model grounds its answer in.

DEFINITION

Lost in the middle

A position bias: accuracy is highest when the needed passage is first or last and dips in between. Named by Liu et al. in 2023. Bigger context windows have not fixed it.

DEFINITION

Grounding

Instructing the model to answer only from the supplied context, to cite the chunk, and to say when the context doesn't contain the answer. An ungrounded RAG answer is a hallucination with extra steps.

06

Measure it or you're guessing.

Five real handbook questions with known correct sources — a golden set. Toggle everything you just built and watch two numbers move independently: recall@k says the right chunk arrived, faithfulness says the answer actually used it. One of these states scores perfect recall and still answers badly.

DEFINITION

Recall@k

Of the chunks that genuinely answer the question, how many appear in the top k. It tells you the retriever did its job — and nothing at all about the answer.

DEFINITION

Faithfulness

The fraction of claims in the answer that are supported by the retrieved context. Measured with an LLM judge against a rubric. A system can score perfect recall and still be wrong.

Index → retrieve → rerank → generate. Evaluate all of it.

Chunk on structure, not on a token count. Retrieve with keywords and vectors, then fuse. Rerank wide-to-narrow. Put the strongest chunk first and fewer of them. Then measure both halves, because recall alone will lie to you.
